# 🧠 Comprehensive Product Review Analysis (Classical NLP Approach)

This project analyzes customer reviews using **traditional NLP** techniques (no Transformers).

## 🏗️ Steps Implemented
- Web scraping (BeautifulSoup)
- Data cleaning (regex, tokenization)
- Language detection & translation
- Sentiment & topic modeling
- Review summarization

## 🧰 Tech Stack
Python, BeautifulSoup, NLTK, Spacy, Scikit-learn, Gensim, Matplotlib

## 📁 Folder Structure
product-review-analysis/
├─ src/
├─ data/
├─ notebooks/
├─ results/
├─ requirements.txt
├─ README.md

## 🚀 How to Run
pip install -r requirements.txt
python src/main.py
